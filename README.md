# Faceless AI YouTube Channel — Launch Kit

Everything needed to launch and run the channel. Work through it in this order:

| Step | File | What it covers |
|---|---|---|
| 1 | `channel/branding.md` | Channel name, handle, bio, banner and logo prompts, the About section |
| 2 | `channel/production-guide.md` | How to turn each script into a finished video in about 30–45 minutes |
| 3 | `channel/30-day-plan.md` | What to post each day, plus the numbers to check every week |
| 4 | `scripts/long/` | Ready-to-record long videos, each with its title, description, tags and thumbnail |
| 5 | `scripts/shorts/shorts-batch-01.md` | 15 ready-to-record Shorts with captions |

## Realistic targets
- **Monetization requirement:** 1,000 subscribers plus either 4,000 watch hours or 10 million Shorts views in 90 days.
- **Realistic date:** March–June 2027 if you post every day as planned. December 2026 is not realistic.
- **Earning before monetization:** affiliate links in every description, starting from the first video (see `channel/branding.md`).

## Rules that keep the channel eligible for monetization
1. Never upload the same template video with only small changes. YouTube's inauthentic-content policy rejects those channels.
2. Each video must carry real information: actual tool steps, comparisons and opinions. The scripts are written that way, so don't swap them for generic AI filler.
3. When AI-generated visuals look realistic, tick **"Altered or synthetic content"** when you upload.
4. Use a voice tool whose **paid plan allows commercial use**. The free ElevenLabs plan does not.
