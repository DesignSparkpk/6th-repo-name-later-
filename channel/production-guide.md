# Production guide — script to upload in about 30–45 minutes

You don't write anything. Open a script file, then follow these steps.

## Tools you need
| Job | Tool | Cost |
|---|---|---|
| Voiceover | ElevenLabs **Starter plan or higher** (commercial license); a free alternative is CapCut's built-in text-to-speech | ~$5/month |
| Editing, auto-captions, stock footage | CapCut desktop | Free |
| Screen recording | OBS Studio, or the Windows Snipping Tool's video mode | Free |
| Images and b-roll | Any AI image generator, plus Pexels for stock clips | Free tier |
| Thumbnails | Canva | Free |

**Voice settings:** pick one calm, confident voice (for example a deep, clear US English male or female voice) and **keep it the same for every video**. Set Stability to about 45%, Similarity to about 75% and Style to 0.

## Steps for each long video
1. **Voiceover (5 min):** copy only the lines under `VO:` into ElevenLabs and download the MP3.
2. **Visuals (15 min):** each `[SCREEN: …]` line tells you what to show:
   - `REC` means record your screen doing that action in the tool.
   - `AI-IMG` means generate the image with the prompt given.
   - `TEXT` means a large animated text overlay in CapCut.
   - `STOCK` means search Pexels or CapCut's stock library for the keyword.
3. **Edit (15 min) in CapCut:**
   - Put the voiceover on the timeline first, then line the visuals up to it.
   - Change the visual every 3–5 seconds, even if it's only a zoom or crop on the same clip.
   - Add auto-captions: bold font, white with a lime highlight on the current word.
   - Music: CapCut's library, "lofi tech" or "corporate minimal", at -25 dB under the voice.
   - Export at 1080p, 30 fps.
4. **Thumbnail (5 min):** use the thumbnail brief in the script file.
5. **Upload:** paste the title, description and tags from the script file. Set the category to "Science & Technology", add an end screen and add the video to a playlist.

## Shorts
- 1080×1920, under 60 seconds, with captions in the center of the screen.
- The hook must appear as on-screen text in the first second.
- Post 2 per day, 6–8 hours apart.

## Upload checklist
- [ ] Title and thumbnail match exactly what the video delivers
- [ ] "Altered or synthetic content" ticked if realistic AI visuals are used
- [ ] Chapters (timestamps) in the description of long videos
- [ ] Pinned comment asking a question
- [ ] Affiliate link page in the description
